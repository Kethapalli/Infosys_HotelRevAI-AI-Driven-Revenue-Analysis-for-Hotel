# 🏨 Hotel Demand Forecasting & Cancellation Analysis (Power BI)

## 📌 Project Overview
This project presents an interactive Power BI dashboard designed to analyze hotel booking performance with a focus on demand forecasting, cancellations, no-shows, and booking behavior.
Using historical booking data and Power BI’s native analytics capabilities, the dashboard helps hotel management anticipate future demand, reduce revenue leakage, and make informed operational decisions.
The solution is business-ready, explainable, and portfolio-focused, built using Power BI, DAX, and Power Query.

## 🎯 Business Objectives
Predict future booking demand and occupancy.

Identify seasonal and trend-based booking patterns.

Analyze cancellation and no-show behavior.

Understand customer booking lead-time patterns.

Support pricing, staffing, and overbooking decisions.

## 📊 Dashboard Features
🔝 KPI Summary

Total Bookings;

Forecasted Bookings (Next 3 Months);

Cancellation Rate (%);

No-Show Rate (%);

Average Booking Lead Time (Days);
